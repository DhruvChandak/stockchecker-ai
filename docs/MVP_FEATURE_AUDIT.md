## Notes

- StockPilot AI remains positioned as an inventory intelligence companion for Tally/Excel/ERP data, not as an accounting, GST, voucher, ledger, or statutory compliance replacement.
- Local backend verification on this PC is blocked unless Java 21 and Maven are installed. Web/mobile checks can run with the existing Node toolchain.
